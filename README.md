# Path Probe

A small native Android app that calls the framework APIs which return file paths and displays the results. It is intentionally dependency-free: plain Java, Android platform APIs, and shell/Make scripts instead of Gradle.

The app is **read-only**. It reports each returned path's status but does not create, modify, or delete files.

## AI authorship

This project was fully created by an AI/LLM agent: OpenCode running DeepSeek V4.1 Flash Free. All application code, resources, build scripts, and documentation in this repository were generated by the agent.

## Features

- Groups results by API family with the API name, returned path, and filesystem status.
- Reports whether each path exists, is a file or directory, is readable, and is writable.
- Shows the canonical path when it differs from the absolute path.
- Shows available and total space for mounted filesystems.
- Tapping a row copies that path; **Copy all** copies the complete plain-text report.
- **Refresh** re-collects paths, which is useful when storage volumes change.
- Handles edge-to-edge system bars with platform APIs only.

## APIs covered

### App internal storage

`getFilesDir()`, `getCacheDir()`, `getNoBackupFilesDir()`, `getCodeCacheDir()`, `getDatabasePath()`, `getFileStreamPath()`, `getObbDir()`, and `getObbDirs()`.

### App external storage

`getExternalFilesDir()` for `null` and every public directory type, `getExternalCacheDir()`, and every entry returned by `getExternalFilesDirs()`, `getExternalCacheDirs()`, and `getExternalMediaDirs()`.

### Device-protected storage

Files, cache, no-backup, code-cache, database, and OBB paths from `createDeviceProtectedStorageContext()` (API 24+).

### Application metadata

`getPackageCodePath()`, `getPackageResourcePath()`, and `ApplicationInfo` fields such as `sourceDir`, `publicSourceDir`, `nativeLibraryDir`, `dataDir`, `deviceProtectedDataDir`, and split source directories.

### Environment

Data, download cache, root, storage, and external storage directories, plus every `getExternalStoragePublicDirectory()` type. Deprecated APIs are marked in the UI.

### Storage volumes

All `StorageManager.getStorageVolumes()` entries and the primary volume directory. Per-volume directories require API 30+.

## Requirements

- Android SDK with **build-tools 37.0.0** and **platform android-37.0**.
- **JDK 17**.
- `zip`.
- `adb` for the install, run, and screenshot targets.

The build script defaults to:

```sh
ANDROID_HOME=/opt/android-sdk
JAVA_HOME=/usr/lib/jvm/java-17-openjdk
```

Override `ANDROID_HOME`, `BUILD_TOOLS`, `PLATFORM_JAR`, or `JAVA_HOME` in the environment if your SDK is installed elsewhere.

## Build

```sh
make
```

This produces:

```text
build/PathProbe.apk
```

The app compiles against API 37, targets API 36, and supports API 26+.

The first build creates a local debug signing key at `.keystore/debug.keystore`. It is only for local testing and is gitignored.

### Make targets

| Command | Action |
| --- | --- |
| `make` / `make build` | Compile, dex, align, and sign the APK |
| `make install` | Build, then `adb install -r` |
| `make run` | Install, then launch `MainActivity` |
| `make screenshot` | Capture the device screen to `build/screenshot.png` |
| `make clean` | Remove `build/` |
| `make keystore` | Create the local debug keystore if needed |

The same actions are available directly through `./build.sh <command>`.

## Build pipeline

No Gradle or Android Gradle Plugin is involved. `build.sh` runs:

1. `aapt2 compile` and `aapt2 link` against `android.jar`, generating `R.java`.
2. `javac` with the Android boot classpath and `core-lambda-stubs.jar`.
3. `d8` with `--min-api 26`.
4. `zip` to add `classes.dex`, `zipalign`, and `apksigner sign`.

## Design notes

- No storage permissions are declared. App-specific external directories work without permissions; public external directories generally are not writable on modern Android, and the app displays that accurately.
- `getDir()` is deliberately omitted because it creates a directory. Some framework getters may still create their standard app-owned directories as a side effect; the app never writes probe files.
- Only public framework methods that return a `File` or path string are covered. Storage Access Framework and `MediaStore` return URIs rather than paths and are out of scope.
- There are no third-party runtime dependencies: no AndroidX, no Kotlin standard library, and no Maven artifacts.
- Source indentation uses tabs, as required by `AGENTS.md`.
